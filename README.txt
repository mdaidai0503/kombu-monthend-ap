月末在庫処理 独立アプリ v1.1.0

【実装】
・前月/当月PDF手動取込
・日高/釧路/根室/釧路棹前の自動分類
・生産年度、会社の自動判定
・指定順に自動並べ替え
・同一対象ページの数量比較（片月だけ存在するページは比較対象外）
・差異ページのみ抽出
・右端約1cmを月別色付け（7月=黄色、8月=赤）
・釧路産昆布/根室産昆布/釧路産棹前昆布を生産年度別に各社合算
・元帳票を背景にした各社合計PDF生成
・結果一式ZIP出力
・PWA対応

【比較方式】
PDF内の数量値を抽出して比較します。会社名や日付などの文字差は数量差異として扱いません。

【集計方式】
同じ産地・同じ生産年度の会社別ページについて、帳票内の同じ位置の数量を加算します。
会社判定できないページは誤集計防止のため自動集計から除外し、画面で注意表示します。

【設置】
GitHub PagesなどHTTPS環境へZIPの中身を配置してください。
PDF.js / pdf-lib / JSZip はCDNから読み込みます。
